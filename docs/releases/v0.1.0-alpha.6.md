## 中文

小群文字聊天测试版。修复丢失父事件响应后的同步停滞、同一设备快速重连
握手、同一身份邀请加入重试、断线后误报同步完成，以及发送保存失败时草稿丢失。
首次使用状态和当前社区标识支持中文/英文。

本机使用独立临时身份、SQLite 与 loopback QUIC/relay 验证；包含离线成员、
服务器重启、重复邀请与重连、移除成员后的访问拒绝、Home Server 迁移后旧服务退出。
完整命令和窗口检查见仓库 `docs/validation/alpha.6.md`。

资产：macOS arm64 原生客户端、Windows x64 原生客户端、Linux x64 Home Server。
`SHA256SUMS.txt` 记录三个压缩包的 SHA-256。发布任务仅在所有构建成功后创建此 Release。

边界：仅测试身份和小群文字；邀请无过期/撤销；手动同步，不是所有成员的送达回执。
没有端到端加密、身份恢复、多设备身份、附件或语音；未验证所有 NAT/公网组合。
二进制没有可信发行者签名或 Apple 公证，不代表生产可用性。
协议和存储格式未变。未部署或更改线上服务器。

## English

Small-group text-chat test alpha. Fixes stalled ancestry fetch after a lost response,
rapid reconnects using the same device, invitation retries for the same identity,
false idle-sync success after disconnect, and draft loss when a local save fails.
Identity readiness and current-community labels follow Chinese/English selection.

Local verification uses isolated temporary identities, SQLite and loopback QUIC/relay:
offline members, server restart, invitation retry/replay, rapid reconnects,
removed-member rejection and old-server shutdown after a signed migration.
Commands and window checks: `docs/validation/alpha.6.md` in the repository.

Assets: macOS arm64 desktop, Windows x64 desktop and Linux x64 Home Server.
`SHA256SUMS.txt` contains SHA-256 checksums for the three archives. This release is
created only after all platform builds succeed.

Boundaries: test identities and small-group text only; no invitation expiry/cancellation.
Sync is manual and local quiescence is not a delivery receipt from every member.
No end-to-end encryption, identity recovery, multi-device identity, attachments or voice.
Not all NAT/public-network combinations are verified. Binaries lack trusted-publisher
signing/Apple notarization and are not production-ready. Protocol and storage formats
are unchanged. No live server was deployed or changed.
